ເປັນຫຍັງຮ້ານອາຫານຂອງທ່ານຈຶ່ງຕ້ອງການສິ່ງນີ້

ລູກຄ້ານັ່ງຢູ່ໂຕະ, ເປີດເມນູ, ເລືອກອາຫານ ແລະສັ່ງອາຫານເອງ — ຮ້ານຂອງທ່ານໄດ້ຮັບອໍເດີທັນທີ.

ລູກຄ້າຕ່າງປະເທດ ສາມາດເບິ່ງເມນູເປັນພາສາທີ່ເຂົ້າໃຈ. ລູກຄ້າທ້ອງຖິ່ນກໍສາມາດສັ່ງອາຫານໄດ້ໄວຂຶ້ນ.

ພະນັກງານໃຊ້ເວລາໜ້ອຍລົງກັບການຮັບອໍເດີແບບເກົ່າ, ການຕອບຄຳຖາມຊ້ຳໆ ແລະການແປພາສາ.

🌏
ໃນມຸມມອງຂອງລູກຄ້າ · 01
ພາສາ

ເລີ່ມຕົ້ນດ້ວຍພາສາ

ລູກຄ້າສະແກນ QR Code ຢູ່ໂຕະຂອງຕົນ ແລະເລືອກພາສາທີ່ຕ້ອງການ.

ຊື່ອາຫານ, ລາຍລະອຽດ ແລະສ່ວນຕ່າງໆໃນເມນູຈະປ່ຽນພາສາໃຫ້ອັດຕະໂນມັດ.

ສາມາດເພີ່ມພາສາໃດກໍໄດ້ ໃຫ້ເໝາະກັບລູກຄ້າຂອງທ່ານ.

ໃນມຸມມອງຂອງລູກຄ້າ · 02
ເມນູ

ເລືອກສິ່ງທີ່ຢາກກິນ

ອາຫານແບ່ງເປັນໝວດໝູ່. ຮູບ, ລາຄາ, ລາຍລະອຽດ, ແທັກ ແລະຕົວເລືອກເພີ່ມເຕີມ ຊ່ວຍໃຫ້ລູກຄ້າຕັດສິນໃຈວ່າຈະສັ່ງຫຍັງໄດ້ໄວຂຶ້ນ.

ເຜັດ, ອາຫານມັງສະວິລັດ, ເມນູແນະນຳ, ຂາຍດີ — ທ່ານສາມາດຕັ້ງແທັກໃດກໍໄດ້ຕາມເມນູຂອງທ່ານ.

🎲 ບໍ່ຮູ້ຈະເລືອກຫຍັງ?
ປຸ່ມ “Surprise Me” ຈະແນະນຳອາຫານແບບສຸ່ມຈາກເມນູ.
ອາຫານ

ເຫັນລາຍລະອຽດຊັດເຈນກ່ອນສັ່ງ

ເປີດເບິ່ງອາຫານ — ເຫັນຮູບ, ລາຍລະອຽດ, ລາຄາ ແລະຕົວເລືອກທີ່ມີ.

ລູກຄ້າສາມາດເລືອກລະດັບຄວາມເຜັດ, ຄວາມຫວານ ຫຼືຕົວເລືອກອື່ນໆ — ໄດ້ໂດຍກົງໃນໜ້າອາຫານ.

ບໍ່ຕ້ອງຖາມພະນັກງານເລື່ອງລາຍລະອຽດເລັກໆນ້ອຍໆທຸກຢ່າງ.

ໃນມຸມມອງຂອງລູກຄ້າ · 03
ການສັ່ງອາຫານ

ສັ່ງອາຫານໄດ້ໂດຍກົງຈາກໂຕະ

ລູກຄ້າເພີ່ມອາຫານໃສ່ກະຕ່າ, ເລືອກ “ກິນຢູ່ຮ້ານ” ຫຼື “ເອົາກັບ” ແລະຢືນຢັນອໍເດີ.

ອໍເດີຈະປາກົດທັນທີໃຫ້ທີມງານຂອງທ່ານເຫັນໃນ Dashboard ແລະໃນ Messenger.

ຫຼັງຈາກສັ່ງອາຫານ

ລູກຄ້າຮູ້ວ່າອໍເດີຢູ່ຂັ້ນຕອນໃດ

ຫຼັງຈາກສັ່ງອາຫານແລ້ວ ລູກຄ້າສາມາດເບິ່ງສະຖານະອໍເດີໄດ້: ຮັບອໍເດີແລ້ວ → ກຳລັງກຽມ → ພ້ອມແລ້ວ.

ບໍ່ຕ້ອງຄອຍຖາມພະນັກງານ: “ອໍເດີຂອງຂ້ອຍພ້ອມແລ້ວບໍ?”

ການບໍລິການ

ພະນັກງານຮູ້ທັນທີ

🔔 ຕ້ອງການຄວາມຊ່ວຍເຫຼືອ?
ກົດພຽງຄັ້ງດຽວ — ທີມງານຂອງທ່ານຈະໄດ້ຮັບການແຈ້ງເຕືອນ.

ການແຈ້ງເຕືອນພ້ອມເລກໂຕະຈະປາກົດໃນ Dashboard ແລະສົ່ງໄປຫາ Messenger ດ້ວຍ.

ພະນັກງານໄປຫາລູກຄ້າ ແລະກົດຢືນຢັນວ່າໄດ້ຈັດການແລ້ວ. ຈົບ.

Admin Panel

ໃນຂະນະທີ່ລູກຄ້າກຳລັງສັ່ງ — ທ່ານເຫັນທຸກຢ່າງ

Dashboard ຂອງຮ້ານສະແດງອໍເດີທີ່ກຳລັງດຳເນີນການ: ເລກໂຕະ · ລາຍການອາຫານ · ຍອດລວມ · ສະຖານະ.

ອໍເດີໃໝ່ຈະປາກົດຂຶ້ນອັດຕະໂນມັດ.

ຮັບອໍເດີ → ປ່ຽນສະຖານະ. ອໍເດີພ້ອມ → ປ່ຽນສະຖານະ.

ລູກຄ້າເຫັນການອັບເດດຢູ່ໃນໂທລະສັບຂອງຕົນ.

ການແຈ້ງເຕືອນ
ເລືອກໄດ້ຕາມທີ່ທ່ານສະດວກ

ການແຈ້ງເຕືອນ — ສົ່ງໄປບ່ອນທີ່ທີມງານຂອງທ່ານໃຊ້ງານສະດວກ

ອໍເດີໃໝ່ ຫຼືຄຳຮ້ອງຂໍຄວາມຊ່ວຍເຫຼືອ ຈະຖືກສົ່ງໃຫ້ທີມງານຂອງທ່ານທັນທີ.

ນອກຈາກ Admin Panel ແລ້ວ ຍັງສາມາດເຊື່ອມຕໍ່ Messenger ໃດກໍໄດ້. ທ່ານໃຊ້ຫຍັງ — ພວກເຮົາກໍເຊື່ອມຕໍ່ໃຫ້ໄດ້.
